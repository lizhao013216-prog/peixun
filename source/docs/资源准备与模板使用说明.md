# 资源准备与模板使用说明

## 四类对象的关系

1. **素材**：模型、图像、文档等可版本化来源。素材有唯一所属系统，默认私有；显式共享只允许其他系统引用。
2. **仿真工程**：本系统正在编辑的工作对象，持有独立场景引用，可保存名称、用途和编辑版本。
3. **场景对象**：工程场景中的实例，引用确定的素材 ID 与版本，并保存自己的对象编号、名称、位置、视图和初始状态。修改实例不会修改素材。
4. **仿真系统模板**：由工程通过配置检查后发布形成的不可变版本，冻结场景、对象、联动、素材依赖和来源。修改时从模板创建独立工程或修订并发布下一版本。

## 示例

操作系统拥有“泵组总成”素材，并将其共享给维修系统。两个系统可分别创建对象实例：操作工程中的实例叫“主泵”，维修工程中的实例叫“待检泵”。二者引用同一素材版本，但位置、初始状态和场景环境相互独立；维修系统不能更改操作系统的源素材。

需要联动时，可在同一工程选择阀门和泵，将“阀门就绪”输出连接到泵的“就绪输入”，并设置“只有阀门就绪才允许启动”。调试实例实际读取这份配置：未就绪会拒绝，设置就绪后泵才运行。调试通过后发布为不可变模板；P3 课件选择该模板版本，从模板对象能力编排教学步骤。

如果课程只是部件识别、结构讲解或单设备检查，工程选择 `NONE` 即可。它仍能调试对象自身的有限动作，不需要为了后续发布强行画设备连接线。

## 当前可用范围

- 三系统素材导入、审核、派生和显式共享。
- 三系统独立工程创建、同域复制、对象增删与属性/环境编辑。
- 保存与刷新恢复、编辑版本冲突提示、未保存离开保护。
- 旧全局配置的确定 ID 只读兼容工程。
- 对象有限动作、输入/输出端口、同类型连接和中文语义规则。
- 后端受控的无环信号传播；循环、非法方向、类型、对象和脚本规则会被拒绝。
- 相互隔离的调试实例、动作拒绝原因、命中规则、前后状态、事件顺序和单实例复位。
- 发布前完整配置检查、不可变模板快照、V1/V2 版本链、发布版本调试和来源追溯。
- 从模板新建独立工程、创建同家族修订，以及模板和素材依赖同时满足时的跨系统复用。
- 操作/维修课程和课时组织、V3课件显式模板绑定、自由步骤增删复制排序、动态对象/动作、类型化参数与条件、分值和模式。
- 课件规则预览、换环境影响检查、独立审核、不可变发布快照和版本修订；原V2课件继续兼容运行。

## 后续阶段

- P2-D 三系统完整闭环和综合兼容回归已经完成。
- P3 已完成：课件选择已发布模板并编排自由教学步骤。
- P4：正式训练实例消费V3发布快照，执行步骤条件、计分、暂停续训和事件回放。

阶段未开放的能力不使用伪按钮代替。V3课件已由P4配置驱动运行时消费冻结发布快照，不会通过旧全局配置暗中传值，也不会落入旧运行器。
