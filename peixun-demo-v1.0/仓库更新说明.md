## 更新现有仓库

你的仓库现有业务目录叫 `peixun-demo-v1.0`，此次保持它不改名。按下表对应覆盖更新；不要把整个 `peixun-demo-v1.2` 文件夹再嵌套放入仓库。

| 本包内容 | 仓库中的对应位置 |
| --- | --- |
| `source/` | `peixun-demo-v1.0/source/` |
| `backend/peixun-demo.jar` | `peixun-demo-v1.0/backend/peixun-demo.jar` |
| `frontend/dist/` | `peixun-demo-v1.0/frontend/dist/` |
| `docs/` | `peixun-demo-v1.0/docs/` |
| `README.md`、`start.bat`、`start.sh` | `peixun-demo-v1.0/`下同名文件 |
| `repository-config/ci.yml` | 仓库根目录 `.github/workflows/ci.yml` |

`source/` 是直接展开的完整源码，不需要应用补丁。根CI配置已按你最新的嵌套源码位置修正；源码内的CI配置保留独立开发项目的相对路径。

本包不附带历史数据库；请保留并备份已有 `backend/.data/`，不要用空目录覆盖。新程序能继续读取已有数据；旧已发布课件不会自动改写。体验新版具体步骤请创建新课件，或从演示中心准备新的完整案例。

若通过本地Git提交，请注意根目录忽略规则可能忽略新生成的dist文件，在仓库根目录执行：

```bash
git add .github/workflows/ci.yml peixun-demo-v1.0
git add -f peixun-demo-v1.0/frontend/dist
git diff --cached --stat
```

检查暂存内容后正常commit、push。不要把node_modules、target、运行日志或新数据库文件提交到仓库。
