# 保障业务共性平台 Demo 1.2

## 启动

需要 Java 17。完整解压后，Windows 双击本目录的 `start.bat`；Linux/macOS 执行 `bash start.sh`。打开 http://127.0.0.1:8080 。先关闭正在运行的旧版程序，防止仍访问旧页面。

交付包不附带历史数据库。运行数据保存在 `backend/.data/`；保留旧版数据时，先停止旧程序并备份该目录，再复制到新版对应位置。已有课件版本不改写。要体验新版具体动作模板，请新建课件或准备新的演示案例。

## 先按这条路线体验

1. 首页选择 **教员：制作与发布课件**。新建课程，填写教学目标，编辑步骤的操作说明、对象、动作和成功结果。
2. 保存后点击 **预览学员视角**，确认学员能理解每一步；提交审核，由其他教员审核，再发布并分配给学员A。
3. 首页选择 **学员：开始我的训练**（或在任务页切换到分配学员），打开该任务。先阅读目标，再开始训练。
4. 每一步先选对象，再点击明确命名的动作按钮。页面显示成功或错误原因；成功后点击 **继续下一步**。
5. 完成后查看成绩、提交反馈，再切换教员检查记录并 **确认证据**。

需要快速展示现有成果时，进入 **演示中心 → 准备一套完整演示案例**。已完成的任务可以 **新建补训**。

## 本轮改变

- 教员在同一课件页面完成步骤配置、预览、审核、发布与分配，并明确知道当前状态和下一动作。
- 学员看到课程目标、任务进度、本步要求、具体按钮、操作结果和下一步；选错对象不会跳步。
- 暂停或刷新可继续原训练；阻止同一任务重复启动；完成后区分训练成绩与教员确认证据。
- 保留现有配色和字号，并同步更新前端与后端运行文件。
