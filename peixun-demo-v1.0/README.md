# 保障业务共性平台 Demo 1.1

## 立即查看新版

需要Java 17。完整解压本包，Windows双击`start.bat`；Linux/macOS执行`bash start.sh`。

打开 http://127.0.0.1:8080 。如果旧版还在运行，请先关闭旧版进程，再启动本包。

1. 首页点击**开始演示**。
2. 演示中心点击**准备一套完整演示案例**，等待自动切换到新工作区。
3. 选择一个系统，点击**开始讲解**，按页面上方的步骤讲解已有成果。
4. 需要亲自操作时选**跟随操作 → 新建练习空间并开始**。按指引切换身份、操作下方业务按钮，再进入下一步。

本包初始没有历史业务数据库，首次通过页面生成案例。数据会保存在`backend/.data/`。可以保留旧版目录作为备份，无须覆盖旧版数据。

## 这次改了什么

- 去掉旧展示名称，统一为保障业务共性平台。
- 正文16px、标题30px、白色卡片和浅蓝背景；强化文字、按钮和状态对比。
- 增加演示中心及三条路线：操作训练9步、维修培训9步、保障筹划与演练14步。
- 每步给出身份、具体操作和预期结果；支持角色切换、上一步/下一步和刷新恢复。
- 浏览器一键生成完整案例，保留原有工作区，训练/演练/施工/归档均通过实际业务接口产生记录。

## 源码就在source目录

`source/frontend/src/`：Vue前端；`source/backend/src/`：Java后端与测试；`source/scripts/`：案例生成与浏览器验证；`source/docs/`：MD文档。

**源码已直接展开，不需要应用补丁。** `source/`是完整开发项目，构建方式见`source/README.md`。
